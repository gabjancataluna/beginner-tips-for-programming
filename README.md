# Programming Tips for Beginners!

Here are a few helpful tips if you are new to coding or exploring this project:

* **Read the error messages:** Don't panic when the code breaks—the terminal usually tells you the EXACT FILE and ISSUE LINE where the issue happened.
* **Use version control:** Commit small changes often so you can easily undo mistakes.
* **Break problems down:** Solve one tiny piece of logic at a time instead of trying to write the whole program at once.
* **Keep code readable:** Use clear variable names (like `userAge` instead of `x`) so your future self understands what you wrote.

> **Pro Tip:** Use `console.log()` or `print()` statements to check what values your variables hold while your code runs.
